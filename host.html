Escolha o caminho

O JockieGuessr-Host.exe é portátil: dois cliques e pronto, sem instalar e sem terminal. Os jogadores continuam no navegador do celular.

  • Baixe o JockieGuessr-Host.exe e coloque numa pasta sua.
  • Abra. Na primeira vez o Windows avisa "editor desconhecido": Mais informações → Executar assim mesmo.
  • O app liga o jogo, o som e o túnel, e abre o painel do host já logado. O guia de primeiros passos aparece sozinho.
  • Abrir o telão (aba Telão): com dois monitores ele vai para o segundo em tela cheia.
Fica salvo Senha do host, sessões, placar e configurações ficam em %APPDATA%\JockieGuessr: sobrevivem a trocar o .exe. Fechar o painel fecha tudo (telão, captura de som e túnel).

O jogo inteiro roda no Linux. O que no Windows usa os .exe nativos, aqui usa o que o sistema já tem: PipeWire para o som e MPRIS para o "agora tocando".

  • Baixe o JockieGuessr-Host.AppImage.
  • Dê permissão de execução e abra com dois cliques:
    chmod +x JockieGuessr-Host.AppImage
  • Confira se o sistema usa PipeWire (a maioria das distros atuais usa). Na lista de apps do som, o nome é o que o app informa ao PipeWire (ex.: "Spotify").
  • Abra o Spotify do Linux: ele informa título, artista, álbum, capa e posição, e aceita tocar/pausar/próxima.
Dados Ficam em ~/.config/JockieGuessr.

Para quem tem o código: precisa do Node.js 22.9 ou mais novo.

  • Instale as dependências:
    npm install
  • Gere o site do jogo:
    npm run build
  • Crie o .env com a senha fixa (gerador logo abaixo).
  • Ligue o servidor. O console mostra os três endereços (jogo, host e telão):
    npm start

Sem HOST_PASSWORD no .env, o servidor cria uma senha nova a cada vez e mostra o link do host já com ela. Para testar o app sem empacotar: npm run app.

Senha fixa (.env)

Pelo terminal, o .env fixa a senha do host e o segredo de sessão: assim ninguém precisa entrar de novo quando o servidor reinicia. (No app, isso já fica guardado sozinho.)

 Conta do Spotify opcional

      
Sem login, a playlist é lida pela página pública (até ~100 músicas) e o automático pula até cair numa música dela. Com login (Premium), o jogo lê todas as músicas das suas playlists, toca a faixa exata e lista as suas playlists num menu.

      
    
        
  • Em developer.spotify.com/dashboard, crie um app com uma conta Premium e marque Web API.
    • 
        
  • Cadastre exatamente este Redirect URI:
    http://127.0.0.1:8790/spotify/callback
    • 
        
  • Copie o Client ID, cole na aba Técnico do painel e clique em Entrar com Spotify (no PC).
    • 
      

      
O login é PKCE: só o refresh token fica no seu PC, e nunca vai para página nenhuma. O jogo nunca chama o controle de volume.

    


    

      
 Link público para jogar à distância

      
No modo À distância, cada um entra de casa por um link público, aberto por um túnel do Cloudflare. Não precisa abrir porta no roteador e o seu IP fica escondido.

      
    
        
  • Instale o cloudflared:
          
    winget install Cloudflare.cloudflared
    
          
    sudo pacman -S cloudflared
    
          (o primeiro no Windows; o segundo no Arch/CachyOS, ou o pacote da sua distro)
    • 
        
  • Aba Som → À distância. O QR do telão passa a usar o link público.
    • 
      

      

        
 Rápido
Um endereço *.trycloudflare.com, sem conta. Muda a cada vez que liga.

        
 Meu domínio
Endereço fixo, como https://jockie.seudominio.com. Precisa de um domínio no Cloudflare (e é o que libera o telão no Discord).

      

      
Configurar o "Meu domínio"

      
    
        
  1. Em dash.cloudflare.com → Networking → Tunnels → Create a tunnel, copie o token do comando de instalação (não precisa rodar o comando).
    2. 
        
  2. Em Routes → Add route → Published application, aponte o subdomínio para o Service URL http://localhost:8790.
    3. 
        
  3. No painel: aba Técnico → Link público → Meu domínio, cole o endereço e o token. Ao conectar, o jogo confere se o endereço chega mesmo nele e avisa se a rota estiver errada.
    4. 
      

    


    

      
 Fontes da letra opcional

      
A letra aparece só quando não entrega resposta. Sem configurar nada, o jogo já usa o LRCLIB (por linha). Para palavra por palavra:

      
    
        
  • Spicy Lyrics (oficial, sílaba por sílaba): crie uma aplicação em developers.spicylyrics.org e cole a chave secreta (sl_sk_…) na aba Técnico. Precisa do id da faixa: no Linux vem do MPRIS; no Windows, da conta do Spotify conectada.
    • 
        
  • NetEase: ligue "Procurar também na NetEase" (não oficial).
    • 
      

    


    

      
 Telão no Discord opcional

      
Precisa do link público com o seu domínio. Depois, uma vez só:

      
    
        
  • discord.com/developers/applications → New Application.
    • 
        
  • Activities → Settings: ligue Enable Activities.
    • 
        
  • Activities → URL Mappings: Prefix / → Target jockie.seudominio.com (sem https://; o painel mostra o seu).
    • 
        
  • Installation: marque Guild Install e User Install; abra o Install Link e adicione ao servidor.
    • 
        
  • Numa call: Atividades (o foguete) → o seu app.
    • 
      

      
Como funciona: o Discord abre a página com ?frame_id=…, o site vira telão e chama o servidor pelo prefixo /.proxy. As fontes vêm do próprio jogo: dentro do Discord nada de fora carrega.

    


    

      
 Controle Android opcional

      
O painel do host no celular, com vibração a cada palpite. A câmera do celular (Android ou iPhone) também abre o painel no navegador, sem app.

      
    
        
  • No celular, abra http://<IP do PC>:8790/download/controle.apk (o card mostra o endereço) ou baixe aqui.
    • 
        
  • No PC, aba Links → Controlar pelo celular → Mostrar QR code e escaneie pelo app. O código vale 2 minutos e uma vez só.
    • 
      

      
Para quem compila npm run build:android (JDK 17 e Android SDK). A chave de assinatura fica na pasta de dados do app, em android/: faça backup, sem ela uma versão nova não instala por cima.

    


    

      
 Checklist da festa

      
    
        
  • Spotify aberto no PC (e a playlist carregada, se for no automático).
    • 
        
  • Modo do som certo: Todos juntos (caixa de som) ou À distância (link público).
    • 
        
  • Na aba Som, o que vai no som está em Spotify (sem as vozes do Discord).
    • 
        
  • Telão aberto no segundo monitor, TV ou OBS (clique uma vez nele, no navegador, para a onda seguir o som).
    • 
        
  • Regras conferidas: campos, pontos, times, rodadas especiais.
    • 
        
  • QR code na tela e galera entrando.
    • 
        
  • Celular do host pareado para comandar do sofá (opcional).
    •
